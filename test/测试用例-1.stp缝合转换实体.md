# 测试用例：1.stp 文件缝合并转换为实体

## 测试用例编号
TC-001

## 测试优先级
P0（最高优先级，核心功能回归测试）

## 测试目的
验证以下核心功能的正确性：
1. 多个Shell缝合为一个Shell
2. 缝合后转换为Solid实体
3. 转换后状态栏信息正确显示（0个Shell, 1个实体）
4. 几何浏览树正确显示拓扑结构

## 测试环境
- 操作系统：Windows 10
- 程序版本：1.0.0
- OpenCASCADE版本：7.7.0

## 测试文件
- 文件路径：`1.stp`
- 文件说明：包含3个独立Shell的STEP文件

## 测试步骤

### 步骤1：启动程序
```bash
cmd /c run_geomprocessor.bat
```
**验证点**：程序成功启动，界面正常显示

### 步骤2：加载测试文件
1. 点击工具栏"📂 打开"按钮
2. 选择 `1.stp` 文件
3. 等待文件加载完成

**验证点**：
- 文件成功加载
- 状态栏显示：`"已加载几何 | 91 个面 | 0 个实体"`
- 左下角浮动标签显示：`"面: 91   Shell: 3   实体: 0"`

### 步骤3：检查初始几何体结构
1. 查看几何浏览树根节点
2. 查看左侧面列表

**验证点**：
- 几何浏览树根节点：`"0个实体, 3个Shell, 91个面, 273条边"`
- 几何浏览树第一层：显示"Shell 1"、"Shell 2"、"Shell 3"
- 面列表：包含 91 个面（面 1 到 面 91）

### 步骤4：执行缝合操作
1. 确认容差值为 `0.1`（默认值）
2. 勾选"水密时转换为实体"选项
3. 点击"执行缝合"按钮
4. 观察进度条和状态栏变化

**验证点**：
- 进度条正常更新
- 状态栏显示缝合过程信息

### 步骤5：验证缝合并转换结果
缝合完成后，检查以下内容：

**状态栏验证**：
- 状态栏显示：`"缝合完成并转换为实体 | 已发送 | 91 个面 | 0 个Shell | 1 个实体"`

**左下角浮动标签验证**：
- 浮动标签显示：`"面: 91   Shell: 0   实体: 1"`

**几何浏览树验证**：
- 几何浏览树根节点：`"1个实体, 1个Shell, 91个面, 273条边"`
- 几何浏览树第一层：显示"实体 1"（不再显示Shell节点）
- 实体 1节点下包含所有面（面 1 到 面 91）

**面列表验证**：
- 面列表仍包含 91 个面
- 所有面正确显示（面 1 到 面 91）
